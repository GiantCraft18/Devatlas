## <span style="color: #b380ff;">✨</span> Возможности

### 🔍 Поиск по всему каталогу

Ищет по названию, описанию, категории, языку и тегам рекомендаций. Совпадения подсвечиваются. Горячая клавиша <kbd>Ctrl</kbd> + <kbd>K</kbd> фокусирует поиск.

### ⭐ Избранное и счётчик просмотров

- Отмечай ресурсы звёздочкой — они сохраняются в браузере
- Счётчик показывает, сколько раз ты открывал каждый ресурс
- Вкладка «Моё» в рекомендациях собирает всё избранное в одном месте

### 🆕 Метки «Недавно добавлено»

Ресурсы, добавленные за последние 30 дней, получают зелёный бейдж **NEW** на обложке. Сразу видно, что каталог живой.

### 🎲 Случайный ресурс

Не знаешь, с чего начать? Нажми <kbd>R</kbd> — откроется случайный ресурс из каталога.

### ⌨️ Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| <kbd>Ctrl</kbd> + <kbd>K</kbd> или <kbd>/</kbd> | Фокус на поиск |
| <kbd>R</kbd> | Случайный ресурс |
| <kbd>T</kbd> | Сменить тему |
| <kbd>Esc</kbd> | Сбросить фильтры |

### 🔗 Поделиться ресурсом

Кнопка «🔗» на карточке:
- **На телефонах** — открывает нативное меню «Поделиться» (Telegram, WhatsApp и т.д.)
- **На десктопе** — копирует ссылку в буфер обмена

### 🌐 Фильтр по языку

Показывай только русскоязычные или только англоязычные ресурсы. Полезно, если учишься на конкретном языке.

### 💰 Фильтр по цене

Три режима: **бесплатно**, **freemium**, **платно**. Студенты обычно ищут только бесплатное — теперь это в один клик.

### ⭐ Рекомендации по группам

Не знаешь, с чего начать? Восемь вкладок подскажут, что смотреть в зависимости от твоей цели:

| Группа | Для кого |
|--------|----------|
| ⭐ **Моё** | Твоё личное избранное |
| 🌱 **Новичкам** | Первые шаги в программировании |
| 🌐 **Веб** | Frontend и backend |
| 🧠 **ML/AI** | Нейросети, машинное обучение |
| 📚 **Книги** | Что почитать |
| 🛠️ **Инструменты** | Что установить |
| 🧮 **Алгоритмы** | Подготовка к собеседованиям |
| 🎨 **Дизайн** | UI/UX и визуал |
| 🚀 **Продвинутым** | Куда расти дальше |

### 🌗 Тёмная и светлая темы

Переключатель в шапке. Выбор сохраняется в LocalStorage — при следующем визите тема та же. При первом заходе тема определяется по системной.

### 📱 Адаптация под все устройства

- **Десктоп** — сетка карточек заполняется автоматически, кнопки действий появляются при наведении
- **Планшет** — 2 колонки, панель фильтров переносится
- **Телефон** — 1 колонка, поиск на отдельной строке, кнопки действий всегда видны

### 📇 Информативные карточки

У каждой карточки:

- 🎨 Градиентная обложка в цвете категории
- 📝 Короткое описание — что это и зачем
- 💰 Метка цены: **Бесплатно** / **Freemium** / **Платно**
- 🌐 Язык: **RU** или **EN**
- ⭐ Рейтинг от 1 до 5
- 🏷️ Категория с иконкой
- 👁 Счётчик просмотров (если ты уже открывал)
- ⭐ Кнопка «В избранное»
- 🔗 Кнопка «Поделиться»
- ➡️ Стрелка, ведущая на ресурс
