### ⭐ Рекомендации по группам

Не знаешь, с чего начать? Восемь вкладок подскажут, что смотреть в зависимости от твоей цели:

| Группа | Для кого |
|--------|----------|
| 🌱 **Новичкам** | Первые шаги в программировании |
| 🌐 **Веб** | Frontend и backend |
| 🧠 **ML/AI** | Нейросети, машинное обучение |
| 📚 **Книги** | Что почитать |
| 🛠️ **Инструменты** | Что установить |
| 🧮 **Алгоритмы** | Подготовка к собеседованиям |
| 🎨 **Дизайн** | UI/UX и визуал |
| 🚀 **Продвинутым** | Куда расти дальше |

### 🌗 Тёмная и светлая темы

Переключатель в шапке. Выбор сохраняется в LocalStorage — при следующем визите тема та же.

### 📱 Адаптация под все устройства

- **Десктоп** — сетка карточек заполняется автоматически
- **Планшет** — 2 колонки
- **Телефон** — 1 колонка, поиск на отдельной строке, шапка компактнее
